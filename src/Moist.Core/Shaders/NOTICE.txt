Bundled GPU upscaling shaders
=============================

These GLSL shaders run through FFmpeg's libplacebo filter (custom_shader_path) to give
moist a GPU, neural-network upscale (the "superres" filter). They are third-party works,
redistributed here unmodified under their original licenses. Both licenses are compatible
with moist's own AGPL-3.0.

  version — see LICENSE.LGPL-3.0.txt, which incorporates the GNU General Public License
  version 3 (LICENSE.GPL-3.0.txt). The licence notice is retained at the top of the file.
  General / live-action luma upscaler.

  Anime / line-art upscaler.

it from this folder by file name at run time.
